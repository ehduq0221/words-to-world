# dy — 송도캠퍼스 경량 3D 맵

## 게임 화면 예시

현재 보정된 캠퍼스 배치를 기본값으로 사용합니다. 상단에는 예산·만족도·평판, 왼쪽에는 학습·생활·연구 시설 탭과 상세 안내, 오른쪽에는 학생 의견과 월별 예산 예시를 표시합니다. 시설 탭과 목록 선택, 카메라 조작을 사용할 수 있습니다. 화면의 운영 수치와 학생 반응은 예시 데이터입니다.

화면 구성은 index.html과 src/style.css, 시설 탭은 src/interaction/gamePreview.js에서 수정합니다.

## 실행

프로젝트 루트에서 다음 명령으로 실행합니다. Python 3가 필요합니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dy
```

브라우저에서 http://localhost:8000 을 엽니다. 종료는 터미널에서 Ctrl+C입니다. HTML 파일을 직접 여는 대신 로컬 서버로 접속합니다. 의존 모듈은 vendor에 포함되어 있어 실행 시 다운로드가 필요 없습니다.

## 조작

- 왼쪽 드래그로 회전
- 오른쪽 드래그로 이동
- 마우스 휠로 확대·축소
- 터치 한 손가락으로 회전, 두 손가락으로 이동·확대·축소

## 파일 구성

| 경로 | 역할 |
| --- | --- |
| src/main.js | 화면 초기화와 모듈 연결 |
| src/data/loadCampus.js | 캠퍼스 데이터 로딩 |
| src/scene/createCampus.js | 건물 외곽선에 높이 부여 |
| src/interaction/createCamera.js | 이동·회전·확대·축소 |
| src/interaction/createLabels.js | 건물 이름표와 겹침 처리 |
| public/data/campus.json | 중복 보정 후 건물 55개의 지도 데이터 |
| public/data/SOURCE.md | 데이터 출처와 확인 사항 |
| vendor/ | Three.js 0.170.0 및 OrbitControls, MIT 라이선스 |

카메라 조작이나 화면 크기가 바뀔 때 렌더링합니다. 이름표는 건물 위치에 표시하고, 서로 겹치면 가까운 건물부터 표시합니다. 건물 또는 이름표를 클릭하면 선택한 건물을 강조하고 왼쪽 패널에 정보를 표시합니다. 건물 외곽선과 원본 높이를 사용하고, 상세 외관은 단색으로 단순화했습니다.

참고 이미지의 빨간선을 기준으로 세로 통로 4개와 위·아래 가로 통로의 간격을 추가로 벌렸습니다. 건물은 외곽 형태를 유지한 채 구역별로 이동하며, 이름표도 함께 이동합니다. 간격 조정값은 src/scene/passageLayout.js의 EXTRA_WIDTH(현재 24)에서 변경합니다. 이 배치는 게임 화면을 위한 조정이며 원본 지도 데이터는 별도로 보관합니다.

초기 데이터는 SMASH-INU의 ODbL 캠퍼스 자료에서 추출했습니다. 실제 2026년 캠퍼스와의 대조와 일부 브이월드 보완 데이터의 공개 배포 조건 확인이 남아 있습니다. 출처는 public/data/SOURCE.md를 참고합니다.
