# 건물 색상·형태 표현 조사

2026-11-06 확인. 대상은 학교 선택 허브 `Hong-Iron/SMASH`가 연결하는 `Hong-Iron/SMASH-INU`이며, 현재 지도에 사용한 원본 커밋 `b608b2ad44f85d4bf81b5484d8cf2f20ec11c397`을 읽었습니다.

## 원본 게임은 어떻게 만드는가

완성된 GLB/GLTF 건물을 내려받아 배치하는 방식이 아닙니다. 지도 데이터의 건물 외곽선·중정·층수·높이를 이용해 자체적으로 입체 형상을 생성하고, 코드로 만든 벽·유리·지붕 재질을 적용합니다.

| 자료 | 원본 처리 | 실제 모습과의 관계 |
| --- | --- | --- |
| `data/campus.json`의 `o`, `ho`, `h`, `lv` | 외곽선·중정·높이·층수로 형상 생성 | 지도·건물통합정보 기반이며 일부 높이는 추정 |
| 같은 데이터의 `rc` | 항공영상에서 추출한 건물별 지붕 대표색 | 지붕색이며 외벽색을 의미하지 않음 |
| `config.json`의 `look` | 건물 ID 또는 이름별 외관 설정 | 공식 안내 사진과 공용 사진을 참고한 9개 건물의 색상 보정 |
| `src/app.html`의 `styleOf`, `makeMaterial`, `patchBuilding` | 기본 스타일 선택 후 벽·유리·창틀·창 간격 등을 코드로 표현 | 사진으로 검토한 값이 없는 건물은 이름·종류·고정 난수 기반 표현 |
| `tools/vworld.py` | 건물정보 보완 및 항공영상 지붕색 추출 | README는 60개 중 56개 지붕색 추출, 47개 층수 확인이라고 설명 |

지붕색은 사진 검토 설정을 우선하고, 없으면 `rc`, 그것도 없으면 기본값을 사용합니다. 경사 지붕은 사진으로 확인된 건물에만 설정합니다. 창·벽돌·유리 표현은 사진을 건물에 붙인 텍스처가 아닌 절차적 재질입니다. 따라서 원본 화면 자체도 정밀 실측 외관을 뜻하지 않습니다.

## 현재 프로젝트와 차이

현재 `campus.json`은 ID·이름·높이·외곽선·중정 위주로 추출했습니다. `createCampus.js`는 공통 녹색 재질 하나를 사용하므로 원본에 있던 지붕 대표색과 건물별 외관 표현은 적용되지 않았습니다. 14호관의 세 형상은 한 건물로 선택하지만 형상 자체는 보존합니다.

원본 LICENSE는 코드·그림·화면 디자인의 복제·수정 배포를 허용하지 않고, 별도로 지도 데이터에는 ODbL을 명시합니다. 이 조사에서는 구현 방식을 읽었으며 원본 셰이더나 외관 설정표를 복사하지 않았습니다. 새 표현은 직접 구현하고, 사진도 표면 텍스처로 복사하지 않고 관찰 근거와 색상 참고 출처를 기록합니다.

## 우리 게임에 적용할 방향

사용자의 목표는 세부 창문·출입구 모델링보다 실제 건물을 알아볼 수 있는 **색상과 덩어리 형태**입니다.

1. 기존 건물 ID와 선택 그룹을 유지합니다. 안내·민원·운영 메뉴 연결은 건드리지 않습니다.
2. 별도 `building-appearance.json`을 만들고, 공식 건물 사진을 직접 확인해 벽색·지붕색·유리 강조색·확인 출처·검토 상태를 기록합니다. 항공 지붕색을 벽색으로 사용하지 않습니다.
3. 먼저 한 개 외곽선에 벽과 지붕을 다른 색으로 적용합니다. 유리 면이 특징적인 건물에만 단순한 색면을 추가합니다. 창틀·벽돌 반복 무늬나 고해상도 사진 텍스처는 생략합니다.
4. 실제로 높이가 크게 다른 동이 있는 건물만 외곽선을 몇 개의 단순한 덩어리로 나누고 높이를 달리합니다. 확인되지 않은 층수·지붕은 임의로 사실처럼 확정하지 않습니다.
5. 도서관·대학본부·강당·기숙사·7/8호관처럼 식별 효과가 큰 건물부터 검토합니다. 색상·형태 변경 뒤에도 14호관 전체 선택과 작은 건물 강조가 유지되는지 확인합니다.

예정 데이터는 `buildingId`, `wallColor`, `roofColor`, `glassColor`, `parts`, `sourceUrls`, `reviewStatus` 정도면 충분합니다. `parts`는 필요한 건물에만 사용합니다. 색상 미확인 건물은 중립색을 쓰고 검토 상태를 남깁니다.

## 승인된 외관 적용

사용자 검토 후 선명한 주황색 외벽(`#e58a3b`), 진한 주황색 하부(`#ca6729`), 도서관 주황색 하부(`#df7838`)를 기본 맵에 적용했습니다. 도서관·7호관·강당은 공식 사진을 관찰해 만든 상세 표현을 사용하고, 나머지 대학 건물은 공통 주황색 벽과 회색 지붕을 사용합니다.

`src/scene/buildingAppearance.js`에서 색상과 사진 출처를 관리하고, `createDetailedBuilding.js`를 지도와 비교 화면이 함께 사용합니다. 실제 측량에 기반하지 않은 창 간격·층 구성·곡선 지붕 세부 비율은 게임용 해석입니다. 지리 위치·외곽선 ID는 유지하며 모든 상세 부재도 같은 건물로 선택됩니다. 선택 시 전체를 단색으로 덮지 않고 원래 색상을 살짝 강조합니다.
