# 축제 스튜디오

기존 게임과 별도로 확인하는 하루 축제 기획·미리보기입니다. 게임 예산·만족도·게임 저장을 읽거나 변경하지 않습니다.

## 실행

프로젝트 루트에서:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

http://127.0.0.1:8000/src/festival/dev.html

1. 제공 차트를 참고한 실제 가수 후보를 최대 3팀 선택합니다.
2. 포스터의 위·아래 버튼으로 순서를 바꿉니다.
3. 초록 A·B 장소·예산·부스·응원봉·색종이 피날레·폭죽 시점을 정하고 기획안을 저장합니다.
4. 미리보기를 누르면 선택한 실제 캠퍼스 건물 앞의 게임용 무대에서 공연이 진행됩니다.
5. 공연 버튼으로 개별 무대를 볼 수 있습니다. 일시정지·다시 보기·닫기 또는 Escape를 사용할 수 있습니다.
6. 소리는 기본으로 꺼져 있습니다. `소리 켜기`를 눌러 Web Audio 합성음을 재생합니다.

미리보기는 준비 4초, 공연당 16초, 공연 사이 3초, 마무리 5초로 하루를 압축합니다. 포스터의 17·19·21시는 게임용 타임테이블이며 실제 축제 공지가 아닙니다. 원래 캠퍼스 지도 형상을 재사용하지만 무대·관객·부스 배치는 가상 연출입니다.

## 파일과 경계

- `index.js`: `initFestival()` 진입 함수와 기획 UI. `#festival` 안에 렌더링합니다.
- `plans.js`: 기획안 생성·검증·비용·브라우저 저장. 선호도 제출과 구분합니다.
- `player.js`: 모달 미리보기·공연 순서·재생 상태. 입력 기획안을 읽기만 합니다.
- `scene.js`: 기존 Three.js·`loadCampus`·`createCampus`·`createCamera` 재사용. 새 엔진 없음.
- `audio.js`: 오리지널 합성 패턴. 외부 음원·영상·API 호출 없음.
- `dev.html`, `dev.js`: 계획서 기준 독립 개발 진입점. `preview.html`은 기존 주소 호환용 이동 페이지.
- `gameApi.js`: 후속 게임 연결의 공개 API 진입점. 현재는 임시 어댑터를 re-export합니다.
- `stubGame.js`: 1차 임시 어댑터. 현재 독립 기능에서는 호출하지 않으며 실제 게임 연결 시 삭제합니다.
- `public/data/festival.json`: 차트 참고 실제 후보·게임 비용·기준 건물 ID·초록 위치 오프셋·축제 구성.

저장 키는 `words-to-world:festival-plans:v1`이고 최대 50개입니다. 새로고침 후 저장 목록에서 불러옵니다. 브라우저·주소·포트가 바뀌면 저장소가 다릅니다. 게임 저장 키 `words-to-world:save`와 분리됩니다. 저장 실패나 손상 데이터가 있으면 메시지를 표시하며 자동 덮어쓰지 않습니다.

## 게임 완성 후 연결 — 아직 미구현

`IMPLEMENTATION_PLAN.md`의 2차 연결 순서를 따릅니다.

1. 기존 화면에 축제 전용 `#festival` 영역·CSS와 진입 버튼을 추가합니다. 다른 담당 패널은 수정하지 않습니다.
2. `src/main.js`에서 `initFestival`을 가져와 지도 초기화 이후 호출하고, 전체 기능 등록 이후 `startGame()`을 호출합니다.
3. 게임 날짜·학기·운영 지표는 쿼리 없는 `../game/index.js` 공개 API로만 연결합니다. `registerArea('festival', ...)`에 학기별 개최 결과를 저장합니다.
4. 실제 개최 버튼은 미리보기 버튼과 구분합니다. 선택 라인업과 게임 학기를 검증한 뒤 `applyEffect`로만 비용·만족도를 반영합니다. 예를 들어 `festival:held:2026-1`로 같은 학기의 중복 개최를 방지합니다.
5. 실제 축제 일정과 하루 개최일은 확인한 자료·사용자 선택으로 결정합니다. 현재는 기획·미리보기만 언제든 가능하며 실제 일정을 주장하지 않습니다.
6. 실제 개최 후 학생 반응을 `addReaction`으로 추가하고, 대사는 지정된 `public/data/dialogues/festival.json`에 둡니다. 예상 반응과 실제 반응을 구분합니다.
7. 3차에 `onSettlementEnd`의 예산 음수 게임 종료와 새 게임 안내를 연결합니다.

현재 `initFestival()`은 데이터 fetch를 위해 비동기 함수입니다. 현재는 게임 영역을 등록하지 않습니다. 나중에 게임 상태를 등록하는 코드를 추가할 때는 `startGame()` 이전에 등록이 끝나도록 호출을 기다려야 합니다.

## 차트 후보와 초록 위치

후보는 사용자 제공 멜론 차트에서 발췌했으며, 출처 수신일은 2026-11-06입니다. 원본 텍스트의 차트 기준 시각은 확인되지 않았으므로 실시간 갱신·현재 순위로 표시하지 않습니다. 후보 카드의 숫자는 제공 자료의 곡 순위입니다. 가수의 실제 음악 장르를 단정하지 않고, 필터는 게임의 노을·아이돌·그루브 공연 연출 분류로 사용합니다.

19호관 오른쪽 초록 A와 왼쪽 초록 B는 이미지에서 추정한 위치입니다. `anchorBuildingId`로 기준 건물을 찾고, 지도 기준 `rightOffset`·`downOffset`과 `scale`로 배치를 조정합니다. 장소 ID는 축제 내부 ID이며, 추후 건물 선택 이벤트와 연결할 때 기준 건물 ID를 사용합니다. 작은 위치 안내도는 원본 좌표 투영이므로 지도 통로 보정이 적용된 실제 3D와 약간 다를 수 있습니다. 미리보기의 `지도에서 위치 보기`로 3D 내 위치도 확인할 수 있습니다.

이전 저장의 가상 가수와 기존 장소는 `archived`로 보존합니다. 새 후보·장소 목록에는 나오지 않으며, 이전 기획안을 불러오면 그대로 복원됩니다. 라인업의 ×로 이전 후보를 제외하고 실제 가수로 교체할 수 있습니다.

폭죽은 색종이 피날레와 별개입니다. 시작·공연 사이·종료 중 선택한 시점만 실행하고, 일시정지·다시 보기에도 대응합니다. 소리를 켜면 직접 합성한 폭죽 효과음이 함께 재생됩니다.
