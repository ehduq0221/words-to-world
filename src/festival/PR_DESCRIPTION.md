[6단계] 축제 기획 및 독립 캠퍼스 체험

실제 캠퍼스에서 자신이 고른 라인업을 체험하도록, 축제 기획과 3D 미리보기를 구현합니다. 사용자가 제공한 멜론 차트를 참고한 실제 가수 후보 12팀과 예시 라인업, 최대 3팀 선택·순서 변경, 기획안 저장·불러오기·삭제·비교를 제공합니다. 비용·공연 시각·섭외 가능 여부·가수별 연출은 게임용 설정입니다.

빠른 보기와 저장 기획안 불러오고 미리보기, 관객 사이 입장·이동·환호를 제공합니다. 같은 아이돌 장르에서도 무대 색·장식·대형·캐릭터 동작·오리지널 합성 음악을 가수별로 구분합니다. 폭죽은 단독 미리보기와 위치 선택을 지원하며 발사·연속 폭발·잔광을 하늘 시점에서 확인할 수 있습니다.

개발 주소: `/src/festival/dev.html` (`preview.html`도 호환). 기존 Three.js·캠퍼스 데이터 재사용, 추가 런타임 의존성 없음. 게임 예산·만족도·게임 저장과 분리하며, 실제 게임 연결은 사용자 요청에 따라 후속 작업입니다. 현재 게임의 `index.html`·`src/main.js`와 다른 기능 폴더는 변경하지 않습니다.
