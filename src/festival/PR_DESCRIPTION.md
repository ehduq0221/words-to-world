축제 기획안을 만들고 실제 캠퍼스 데이터를 사용한 3D 공연을 독립 화면에서 미리 확인할 수 있도록 합니다. 최대 3팀 선택·순서 변경, 여러 기획안 저장·불러오기·삭제·비교, 세 장르의 관객·조명·합성음 연출을 제공합니다.

사용자 요청에 따라 게임 연결은 후속 작업입니다. 기존 index.html·src/main.js·운영 패널은 변경하지 않았으며, 미리보기는 실제 게임 예산·만족도·게임 저장을 바꾸지 않습니다. 실제 개최·학기별 정산·학생 반응 연결은 계획서의 2차, 게임 종료는 3차 대상입니다. 후보·비용·공연 시간과 배치는 게임용 예시입니다.

실행: 프로젝트 루트에서 `python3 -m http.server 8000 --bind 127.0.0.1`, `/src/festival/preview.html` 방문. 확인 후 다른 팀원이 검토·병합해야 합니다.
