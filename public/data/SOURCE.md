## 로컬 시설 안내·야외 운동장 보완 (2026-11-06)

- 건물명·주요 용도·층별 시설은 인천대학교 공식 캠퍼스맵의 송도캠퍼스 건물 목록과 상세 안내를 확인해 요약했습니다.
- 공개 목록: https://www.inu.ac.kr/campusMap/inu/8/artclList.do
- 공개 상세: https://www.inu.ac.kr/campusMap/inu/{artclSeq}/artclDetailView.do (실제 번호별 출처는 facilities.json에 기록)
- 원본 지도 ID는 유지하며, 공식 명칭은 facilities.json에서 관리합니다. 14호관의 여러 지도 형상에는 호관 전체 안내를 공유하고 형상별 동·호실 연결은 미확인으로 남깁니다.
- 공식 안내와 연결되지 않은 형상은 기타·확인중에 포함하며, 이름표 숨김 설정은 유지합니다.
- 대운동장은 `outdoor:main-field`로 추가했습니다. 기존 55개 건물·형상에 야외 시설 1개를 더해 전체 지도 시설은 56개입니다.
- 운동장의 위치·형태는 사용자 제공 실제 지도에서 운동장본부석 옆 배치를 참고한 게임용 단순화입니다. 측량 좌표·실제 규격·정확한 트랙 레인 수를 뜻하지 않습니다.
- 운동장 용도 확인: https://www.inu.ac.kr/bbs/inu/243/271192/download.do

## 14호관 통합 선택 및 미확인 형상 제거

- 이름이 확인되지 않아 이름표를 숨겼던 형상 12개를 사용자의 요청으로 campus.json과 시설 안내에서 제외했습니다.
- 14호관은 기존 형상 ID 세 개를 보존하고 selectionGroupId를 way/367504003으로 묶었습니다. 외곽 형태를 유지하면서 목록·이름표·선택 이벤트는 하나의 건물로 처리합니다.
- 현재 지도 형상은 44개, 통합된 선택 대상은 42개입니다. 삭제 ID 목록은 facilities.json의 removedBuildingIds에 기록합니다.
